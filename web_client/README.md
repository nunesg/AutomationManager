# Automation Manager Web Client

This application allows the client to interact with the AM server.

## How to run it?

- To run the web client server locally you can use the "run_server.sh" script. By default it will use localhost, but if you wanna use the prod backend you can run pass a "--prod" flag to it
- `user@web_client $` `./run_server.sh --prod`
